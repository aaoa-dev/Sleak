Most UI fails on small decisions

A radius reused at every level. Accent on every icon. Text crowding a corner. A button whose label reads dark on its own fill. Invisible in the code, obvious on screen, and the reason a layout looks assembled from templates. Sleak names each one, attaches a number you check, and gives the smallest fix.

14 rules, each with a measurement you can check

Each maps to a reference with the full logic, CSS, and an audit. The mono line is what you verify.

Concentric radius

Nested corners share one curve axis; padding is the gap between them.

parent − padding = child 02

Section eyebrows

Kickers weaken when repeated; the heading carries the section.

≤ 1 per page · hero: none 03

Intentional accent

Full accent pulls the eye to the one primary task, not decoration.

1 focal point / view 04

Accent-hue blacks

Tinted darks take the accent's hue, so nothing clashes.

sat > 0 → hue = accent 05

Contrast

Readable by the math and by perception, checked on the render, not the token.

WCAG 4.5 + APCA Lc 75 06

Typography

Line length, alignment, and size matched to viewing distance.

≈ 55ch · 7–12 words 07

Layout & spacing

Separate with space and surface tiers, not edge-to-edge rules.

0 full-bleed dividers 08

Cards & buttons

Whole cards click; icons sit in a square with uneven horizontal padding.

icon side ≈ ½ text side 09

Motion budget

Prefer subtle over none; one expressive moment; vary the recipe.

≤ 150ms · ease-out 10

Content & copy

Lead with the action; drop the fluff; be specific.

verb + object 11

Accessibility

Names, focus, keyboard, targets, and cues beyond colour.

names · focus · ≥ 44px 12

UX & states

Design every state and use real elements, not the happy path alone.

every state · real elements 13

Design system foundations

Tokens as one source of truth, lean sets, atomic components.

Principles

How a pass runs

Fixed order. The verify step reads rendered pixels, not source, contrast and geometry hide in that gap.

Context

Pin the product, audience, and constraints. Match the existing system first.

Audit

Scan against the checklist. Flag issues by category and severity, High before ship.

Fix

Apply the smallest change that fixes the decision. Each reference has the CSS.

Verify

Re-run the checklist on the rendered output. Contrast and geometry hide in the gap between source and screen.
